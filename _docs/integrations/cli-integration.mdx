## Installation

Download the suitable EkLine binary for your operating system from this [link](https://github.com/ekline-io/ekline-cli-binaries/releases/latest).

## Usage

To use the EkLine CLI, execute the following command:

```bash
ekline-cli [options]
```

### Options

The following options work with the EkLine CLI:

- **v, --version**.

  Displays the current version of the EkLine CLI.

- **d, --debug**.

  Enables verbose logging to give detailed debug information.

- **o, --output `<output-file-name>`**.

  Specifies the output filename. If not provided, the terminal displays the output. For JSON output, use the file extension **`.jsonl`**. For CSV output, use the file extension **`.csv`**.

- **ns, --no-suggestion**.

  Disables suggestions. Please note that suggestions are only generated for **`.jsonl`** or **`.csv`** output formats.

- **i, --ignore `<rules>`**.

  Ignores specified rules during the check. Pass rules as comma-separated values. For example, **EK1,EK4**.

- **cd, --content-directory `<contentDirectory...>`**.

  Specifies the directory paths where you locate the content files. Paths should be relative to the current directory.

- **et, --ek-token `<token>`**.

  Authorizes your EkLine API token. This field is mandatory.

- **ai-suggestions**.

  Enables AI-generated suggestions during the documentation review process. By default, this feature is not active. When activated, AI generates and includes suggestions in the review output.

- **h, --help**.

  Displays the command's help information.


## Examples

Below are a few examples of using the EkLine CLI:

1. **Running EkLine CLI and ignoring specific rules**.

   ```bash
   ekline-cli -i EK1,EK4 --ek-token YOUR_EKLINE_TOKEN
   ```

2. **Running EkLine CLI and specifying a content directory**.

   ```bash
   ekline-cli -cd ./content --ek-token YOUR_EKLINE_TOKEN
   ```

3. **Running EkLine CLI with AI suggestions enabled**.

   ```bash
   ekline-cli --ai-suggestions --ek-token YOUR_EKLINE_TOKEN
   ```

Make sure to replace **`YOUR_EKLINE_TOKEN`** with your actual EkLine API token in these examples.
